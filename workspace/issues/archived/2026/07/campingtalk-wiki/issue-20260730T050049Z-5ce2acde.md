## Summary

knowledge-curation.md Line 45-46에 따르면 report(및 policy, guide, decision, spec, reference) 타입은 RB-CUR-006 Gate(Evidence, PII, 참조 무결성, 전체 Validator)만 통과하면 별도 사람 Review 없이 자동 active 전환이 가능합니다.

하지만 현재 dawn-curation 파이프라인은 모든 Bundle을 일괄적으로 review_state: pending으로 설정하여 사람 승인이 필요하다고 표시합니다. 이로 인해 일일 리포트에서 실제로 리뷰가 필요 없는 report Bundle까지 매일 pending 목록에 포함됩니다.

runbook과 manual만 사람 검토가 필요하고, 나머지 타입은 auto-promote하도록 파이프라인 수정이 필요합니다.

## Expected result

report Bundle은 Evidence/PII Gate 통과 후 review_state: approved로 자동 생성되어 daily report에서 pending으로 잡히지 않는다

## Actual result

report Bundle도 review_state: pending으로 생성되어 매일 daily report에서 사람 승인 대기로 표시된다
