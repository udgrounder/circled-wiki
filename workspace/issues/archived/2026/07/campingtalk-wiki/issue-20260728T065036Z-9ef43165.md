# dawn-curation.py 5단계가 circled-wiki 공식 create-bundle/apply-bundle-revision을 우회함

## Summary

~/.hermes/scripts/dawn-curation.py의 5단계(Claude Code curation)는 circled-wiki CLI의 create-bundle/apply-bundle-revision을 호출하지 않고, 외부 'claude -p' 프로세스에 Write/Bash 도구를 주고 Bundle 파일을 저장소에 직접 쓰게 한다.

## Expected result

Bundle 생성/개정은 create-bundle 또는 apply-bundle-revision(및 이들이 내부적으로 강제하는 Evidence 존재 확인, RB-KNW-026 canonical ID, validate_repository 전체 재검증, runbook/manual Review 카드 게이트)을 거쳐야 한다.

## Actual result

Claude Code가 Write 도구로 knowledge/bundles/ 아래에 파일을 직접 생성하므로 위 게이트를 전부 우회한다. 실제로 이 경로로 생성된 Bundle 3건이 legacy ID 형식(id: knowledge://..., 파일명 {slug}_{uuid}.md)으로 남아 현재 validate 71 ERROR 중 3건의 원인이다.

## Impact

저장소 전체 validate가 71 ERROR인 상태에서는 공식 create-bundle/apply-bundle-revision이 validate_repository() 전체 재검증에서 항상 실패하므로 어차피 신규 Bundle을 만들 수 없지만, 그 이전까지는 이 우회 경로 때문에 검증되지 않은 Bundle이 반복 생성되어 왔다.
