## Summary

~/.hermes/scripts/dawn-curation.py의 5단계(Claude Code curation)를 실행하기 전 점검하던 중 두 가지 결함을 발견함. (1) find_new_evidence(since_hours=36)가 36시간보다 오래된 미정제 Evidence를 대상에서 제외한다. 실제 확인 시점(2026-07-28) 기준 미정제 Evidence 127개 중 62개가 36시간을 넘겨 있었다. (2) build_claude_prompt()에 내장된 Bundle 생성 지침이 legacy 형식(파일명 {slug}_{uuid}.md, id: knowledge://camping-talk/{domain}/{slug}_{uuid})을 하드코딩하고 있는데, 이 저장소는 이미 커밋 a6e7caf/dc09750에서 OPERATING_RULES.md RB-KNW-026의 canonical 형식({slug}.md, id: bundle/{organization_id}/{slug}--{bundle_uuid})으로 전환을 완료한 상태다. 스크립트를 그대로 실행하면 legacy 형식 Bundle이 다시 생성되어 추후 재정규화가 필요해진다.

## Expected result

find_new_evidence는 curated_into가 아니라 Bundle의 evidence: 필드를 기준으로 미정제 Evidence를 판단하고 시간 제한 없이 전체 대상을 포함해야 하며, build_claude_prompt의 Bundle 템플릿은 RB-KNW-026 canonical 형식을 사용해야 함

## Actual result

find_new_evidence(since_hours=36)가 시간 기준으로 대상을 제한하고(127개 중 62개 누락), 내장 프롬프트가 legacy Bundle ID 형식을 지시함

## Impact

이번 실행에서는 사용자 지시에 따라 스크립트를 수정하지 않고 수동으로 우회 처리했음(대화 세션 내 직접 정제). 다음 새벽 자동 실행 시 스크립트가 그대로면 동일한 시간 누락과 legacy ID 생성이 재발함
