# Slack 대화 수집(slack-capture.py)이 ended_at=NULL인 활성 세션을 수집하지 못함

- Issue ID: `issue-20260721T111930Z-233a64c1`
- Recorded at: 2026-07-21T11:19:30.390969+00:00
- Reported by: Hermes Agent
- Reported from: automation
- Area: integration
- Severity: high
- Status: open

## Summary

slack-capture.py 스크립트의 SQL 쿼리에 ended_at IS NOT NULL 조건이 있어, Slack 세션(24개 모두 ended_at=NULL)이 전혀 수집되지 않음. 원인은 Slack 세션이 자연스럽게 종료되지 않아 ended_at이 설정되지 않기 때문. 수정: 30분 이상 메시지가 없는 활성 세션도 수집하도록 쿼리 추가, idempotency_key는 slack-capture-active-{session_id}로 분리

## Expected result

Slack 대화가 10분마다 slack-capture.py에 의해 수집되어 cpt-wiki knowledge/inbox/slack/로 전달되어야 함

## Actual result

ended_at=NULL 조건으로 인해 24개 Slack 세션 중 단 하나도 수집되지 않음. capture script가 항상 '수집할 새 대화 없음' 출력

## Reproduction or context

1. Slack 채널에서 10분 이상 대화 진행 2. slack-capture.py cron 실행 3. state.db에서 ended_at=NULL인 세션은 쿼리에서 제외됨 4. 수집 미발생

## Related paths or artifacts

- `/home/cpt/.hermes/scripts/slack-capture.py`

## Improvement hint

fix: ended_at IS NOT NULL 조건만 의존하지 말고, 30분 이상 메시지가 없는 활성 세션도 subquery(MAX(m.timestamp) < threshold)로 수집. 이미 수정 완료 (slack-capture.py v2.1)
