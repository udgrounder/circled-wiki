# migrate-document-ids가 새 Bundle Identity Contract(RB-KNW-026)를 만족하지 못함

- Issue ID: `issue-20260727T081902Z-e96a7131`
- Recorded at: 2026-07-27T08:19:02.817258+00:00
- Reported by: claude-code
- Reported from: agent
- Area: cli
- Severity: medium
- Release observed: v1-637207c8d2e0
- Status: open

## Summary

circled-wiki.py migrate-document-ids --apply를 dry-run으로 확인한 결과, 기존 오염된 id 필드(파일명 전체와 .md 확장자가 그대로 박힌 값, 예: bundle/camping-talk/{slug}_{uuid}.md)에 --{uuid}만 덧붙이는 동작만 수행한다. RB-KNW-026이 요구하는 canonical 형식(파일명 {slug}.md, id: bundle/{organization_id}/{slug}--{bundle_uuid})으로 파일명을 rename하거나 id의 slug 부분을 정제하지 않아, 이 명령만으로는 신규 규칙을 충족할 수 없다.

## Expected result

migrate-document-ids --apply 실행 시 파일명이 {slug}.md로 rename되고 id가 bundle/{organization_id}/{slug}--{bundle_uuid} canonical 형식으로 정규화되어야 한다

## Actual result

id 필드에서 기존 값(파일명 전체 문자열, .md 확장자와 _{uuid} 포함)을 그대로 두고 뒤에 --{uuid}만 추가한다. 파일명 rename은 수행하지 않는다.

## Impact

Bundle Identity Contract 정규화를 CLI에 의존할 수 없어 수동/스크립트 방식으로 우회해야 함

## Reproduction or context

python3 .circled-wiki/bin/circled-wiki.py migrate-document-ids (dry run) 실행 후 id_map 출력 확인 — knowledge/bundles/ 내 22개 legacy 파일 전부 동일 패턴

## Related paths or artifacts
