## Summary

현재 RB-KNW-011은 runbook만 knowledge/bundles/<domain>/runbooks/ 하위 폴더에 저장하도록 규정하고, repository.py의 create_bundle 라우팅도 bundle_type=='runbook'일 때만 bundle_directory에 'runbooks'를 추가한다. manual 타입은 동일한 절차적/운영 문서 성격(RB-CUR-001~004에서 runbook과 항상 같은 Review Gate를 적용받음)임에도 domain 폴더 바로 아래(report/guide/decision 등 다른 타입과 동일 위치)에 저장된다. kjkim이 manual도 runbook과 같이 전용 하위폴더(예: manuals/)로 분리 저장하길 요청함.

## Expected result

manual 타입 Bundle 생성 시 knowledge/bundles/<domain>/manuals/<slug>.md 경로에 저장되어야 한다(runbook의 knowledge/bundles/<domain>/runbooks/ 규칙과 동일한 구조).

## Actual result

manual 타입은 knowledge/bundles/<domain>/<slug>.md에 저장된다. runbook만 하위 runbooks/ 폴더로 분리되고 manual은 예외 없이 domain 폴더 최상위에 다른 직접생성 타입들과 함께 위치한다.

## Impact

낮음(운영 편의성 문제, 데이터 무결성이나 보안에는 영향 없음). 다만 문서 유형별 탐색 일관성이 떨어짐.

## Reproduction or context

circled_wiki/core/repository.py의 create_bundle(): bundle_directory = knowledge_root/bundles/domain; if bundle_type == 'runbook': bundle_directory = bundle_directory/'runbooks' — manual에 대한 분기가 없음을 확인.
