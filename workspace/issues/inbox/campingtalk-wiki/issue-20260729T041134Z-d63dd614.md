# promote-curation-candidate가 모든 Bundle에서 'Evidence checksum is stale'로 실패함

- Issue ID: `issue-20260729T041134Z-d63dd614`
- Recorded at: 2026-07-29T04:11:34.900687+00:00
- Reported by: claude-code
- Reported from: agent
- Area: cli
- Severity: high
- Release observed: v1-db3404460cc5
- Status: open

## Summary

create-bundle(직접 생성 경로)로 만든 Draft는 extensions.curation.evidence_checksum이 전혀 채워지지 않는데, promote_curation_candidate는 evidence.checksum과 curation.evidence_checksum(None)을 비교해 항상 불일치로 처리한다. 그 결과 review_state가 approved인 기존 Bundle을 포함해 저장소의 모든 Bundle(29건, active 0건)이 active로 승격된 적이 한 번도 없다.

## Expected result

review_state: approved이고 다른 Gate(Evidence·PII·참조 무결성·Validator)를 통과한 Draft는 promote-curation-candidate로 active 승격이 가능해야 함

## Actual result

promote-curation-candidate 호출 시 'candidate promotion Evidence checksum is stale' 오류로 항상 실패함(review_state와 무관하게 curation.evidence_checksum이 비어있는 모든 Bundle에서 재현)

## Impact

저장소 전체 Bundle 29건이 draft에 머물러 있고 active가 0건 — knowledge-curation Contract의 Promotion Gate 단계가 create-bundle(직접 생성) 경로로 만든 모든 Draft에 대해 사실상 막혀 있음

## Reproduction or context

python3 .circled-wiki/bin/circled-wiki.py promote-curation-candidate --bundle 'bundle/camping-talk/executive-meeting-20260722--479aa4d1-9c8f-4b34-a99f-299df58cbd24' --actor test --security-receipt test (review_state: approved인 기존 Bundle에서도 동일하게 재현됨, 실패 시 원본은 자동 롤백되어 부작용 없음)

## Related paths or artifacts

- None recorded.

## Improvement hint

promote_curation_candidate가 evidence_checksum이 없는 경우 evidence 목록의 실제 현재 checksum을 신뢰하도록 하거나, create_bundle이 생성 시 extensions.curation.evidence_checksum(및 generated_by)을 채우도록 수정 필요

## Cause hypothesis

create_bundle()이 extensions.curation.evidence_checksum·generated_by를 채우지 않는 반면 promote_curation_candidate()는 이 필드가 존재한다고 가정하고 비교함. materialize_curation_candidate(자동 adapter 경로)만 이 필드를 채우므로, 직접 create-bundle로 만든 Draft는 구조적으로 승격 불가능한 상태로 보임
