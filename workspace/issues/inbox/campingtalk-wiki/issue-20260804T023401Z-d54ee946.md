# update_existing Review 카드의 body를 델타로 채우면 승인 시 대상 Bundle 본문 전체가 삭제될 위험

- Issue ID: `issue-20260804T023401Z-d54ee946`
- Recorded at: 2026-08-04T02:34:01.737600+00:00
- Reported by: claude-code
- Reported from: agent
- Area: agent_rules
- Severity: high
- Release observed: v1-f7beac49d898
- Status: open

## Summary

create-curation-review로 recommendation: update_existing 카드를 만들 때 --output의 body에 '새로 추가할 내용'만 넣어도 스키마·문서상 통과되지만, apply-approved-curation-update가 승인 시 body로 대상 Bundle 본문 전체를 교체하기 때문에 기존 내용이 전부 삭제될 뻔했다.

## Expected result

knowledge-curation.md 또는 CurationOutput 스키마 설명이 update_existing 카드의 body는 대상 Bundle의 기존 내용을 포함한 전체 신규 본문이어야 한다고 명시하거나, Runtime이 body가 비정상적으로 짧아지는 update_existing 적용을 경고·차단해야 한다.

## Actual result

2026-08-04 Inbox/Curation 정제 작업에서 update_existing Review 카드 11건을 body에 추가분 섹션 텍스트만 담아 생성했고, 기존에 있던 Review 카드 1건(review-b784e9c0)도 동일하게 델타만 담고 있었다. 승인·적용 직전 apply_approved_curation_update 구현(body=output.body로 전체 교체)을 코드로 확인해 문제를 발견했고, 12건 모두 대상 Bundle의 현재 전체 본문에 신규 사례를 병합한 뒤 재작성해 승인·적용했다(commit dab937e). 사전에 발견해 실제 데이터 손실은 없었다.

## Impact

8개 active/draft Bundle(캠핑장 입점/CS 상담 이력, 신규입점 상담 사례집 2건, 기획전 경품 추첨 이력, 여기어때 데이터요청 이력, 도봉산점/진주점 단체예약 사례집, 법인카드 비용정산 가이드, Knowledge OS 매뉴얼)의 기존 본문이 삭제될 뻔했음. 사전 발견으로 실제 반영 전 차단해 데이터 손실은 없었음.

## Reproduction or context

create-curation-review --output에 recommendation update_existing이 되도록 existing_bundle_candidates를 채우고 body를 대상 Bundle 전체가 아닌 새 섹션 텍스트만 넣어 카드를 생성한 뒤 decide-curation-review --action approve, apply-approved-curation-update를 실행하면 대상 Bundle 본문이 그 짧은 텍스트로 전부 교체된다.
