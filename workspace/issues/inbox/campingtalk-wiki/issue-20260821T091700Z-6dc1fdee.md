# active Runbook 승격 요건('extensions.workflow.learning', 본문 '## Workflow Summary')이 스키마/CLI 어디에도 문서화되어 있지 않음

- Status: open

## Summary

runbook 타입 Bundle을 promote-curation-candidate로 active 승격하려면 (1) extensions.workflow.learning 블록과 (2) 본문에 리터럴 '## Workflow Summary' 헤딩이 반드시 필요하다. 둘 다 .circled-wiki/schemas/bundle.schema.json에는 없고, create-curation-review/review-curation-candidate 등 어떤 CLI도 사전에 요구하거나 채워주지 않으며, promote-curation-candidate 실행 시점에야 에러 메시지로만 드러난다. 이번에 kjkim이 이미 내용을 승인한 runbook 1건(ai-promotional-image-production)이 이 두 요건 때문에 3주간 status: draft로 방치되어 있었다.

## Expected result

runbook 생성/승인 시점(create-curation-review 또는 review-curation-candidate)에 extensions.workflow.learning과 '## Workflow Summary' 요건이 스키마 또는 CLI 유효성 검사로 사전에 안내되거나, 최소한 .circled-wiki/schemas/bundle.schema.json에 문서화되어야 한다.

## Actual result

두 요건은 validator.py의 promote-curation-candidate 실행 경로에서만 검사되며, 실패 시 각각 별도의 에러 메시지('active Runbook must define extensions.workflow.learning', "active Runbook body must include a non-empty '## Workflow Summary' section")로만 순차적으로 드러난다. Review 승인 단계에서는 아무 신호가 없어, 승인자는 내용이 승인되면 자동으로 게시된다고 오인하기 쉽다.

## Impact

승인권자가 이미 내용을 승인한 runbook/manual이 스키마 요건 미충족으로 조용히 draft에 머물러 게시되지 않는 상태가 몇 주간 지속될 수 있음(오늘 실제로 2건 발견, 각각 3주·2주 방치).

## Reproduction or context

임의의 runbook 타입 Bundle을 create-curation-review로 만들고 decide-curation-review --action approve + review-curation-candidate --action approve까지 진행한 뒤 promote-curation-candidate를 실행하면, extensions.workflow.learning이 없으면 먼저 그 에러가 나고, 추가한 뒤 재실행하면 본문에 '## Workflow Summary' 섹션이 없으면 두 번째 에러가 난다.

## Related paths or artifacts

- `.circled-wiki/runtime/circled_wiki/core/validator.py`
- `.circled-wiki/schemas/bundle.schema.json`

## Improvement hint

bundle.schema.json의 runbook 타입 definition에 workflow.learning을 required 필드로 명시하고, '## Workflow Summary' 본문 요건은 OKF 본문 검증 규칙(RB-KNW 계열)에 명시적으로 추가. 또는 review-curation-candidate 승인 시점에 두 요건을 미리 검사해 승인자에게 즉시 알려주도록 이동.

## Cause hypothesis

런타임 업그레이드 과정에서 active Runbook 검증 규칙이 validator.py에 먼저 추가되고, JSON 스키마·CLI 사전 검증 반영이 후속 작업으로 누락된 것으로 추정.
