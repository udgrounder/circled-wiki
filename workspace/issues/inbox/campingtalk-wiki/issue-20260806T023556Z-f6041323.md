# manual/runbook 자동 Draft 생성 시 slug 지정 수단이 없어 한글 제목이면 의미없는 checksum-suffix slug가 생성됨

- Issue ID: `issue-20260806T023556Z-f6041323`
- Recorded at: 2026-08-06T02:35:56.724971+00:00
- Reported by: kjkim
- Reported from: user
- Area: runtime
- Severity: medium
- Release observed: v1-fef5595e5df4
- Status: open

## Summary

materialize_curation_candidate()가 manual/runbook Draft를 만들 때 curator가 slug를 지정할 방법이 없어 내부적으로 _safe_slug(title, checksum)을 호출한다. 이 함수는 title에서 ASCII[a-z0-9]만 남기고 나머지는 버린 뒤 checksum 앞 12자를 덧붙이는데, 이 Wiki는 title이 거의 항상 한글이라 ASCII 잔존 부분이 거의 없어 'ca-4927e3258f00' 같은 의미없는 slug가 나온다. CurationOutput/generate_curation_review/decide_curation_review 경로 전체에 slug 필드가 없다. create-bundle CLI는 --slug를 받지만 manual/runbook은 DIRECT_DRAFT_TYPES가 아니라 이 CLI로 생성할 수 없다(Review Gate 강제).

## Expected result

manual/runbook도 report/guide 등 direct-creation 타입과 동일하게, 큐레이터(Agent 또는 create-curation-review 호출자)가 의미 있는 영어 slug를 명시적으로 지정할 수 있어야 하며, 미지정 시에도 checksum-suffix보다 나은 fallback(예: title 로마자 표기 시도, 또는 실패 시 명확히 'needs_review' 처리)이 있어야 한다.

## Actual result

curation_contract.CurationOutput에 slug 필드가 없고, curation.py의 materialize_curation_candidate()가 무조건 _safe_slug(output.title, checksum)으로 slug를 결정한다. 한글 title에서는 checksum 앞 12자만 남는 수준으로 퇴화한다(예: 'ca-4927e3258f00.md'). 이 저장소의 기존 manual/runbook 3건은 RB-CUR-001 Review Gate 도입 이전 create-bundle --slug 직접 생성 시절 파일이라 이 결함을 겪지 않았을 뿐, 현재 경로로 만들면 항상 재현된다.

## Impact

탐색성 저하 — 파일명만 봐서는 내용을 알 수 없음. 데이터 무결성·보안 영향은 없음. 이번 건은 rename으로 사후 수정 가능하나, 향후 생성되는 모든 한글 제목 manual/runbook에서 반복될 결함.

## Reproduction or context

circled_wiki/core/curation.py: _safe_slug()는 re.sub(r'[^a-z0-9]+', '-', title.lower())로 title을 정리한다. title이 '관리센터(CA) 신규 캠핑장 입점 세팅 절차'이면 결과가 'ca'뿐이고, f'{ascii_title[:48] or curated}-{checksum[:12]}'로 'ca-4927e3258f00'이 된다.

## Improvement hint

CurationOutput과 create-curation-review --output JSON에 선택적 slug 필드를 추가해 큐레이터가 직접 지정하게 하고, materialize_curation_candidate()는 지정된 slug를 우선 사용하며 SAFE_PATH_SEGMENT 검증만 적용. 미지정 시에는 현재처럼 자동 생성하되 ASCII 잔존 길이가 너무 짧으면(예: 3자 미만) 'needs_review'로 막아 이 상태로 조용히 active까지 승격되지 않게 한다.
