# inbox-inspection.md이 참조하는 inbox-sensitivity-review.md 정책 문서가 실제로 존재하지 않음

- Issue ID: `issue-20260803T110654Z-b717028e`
- Recorded at: 2026-08-03T11:06:54.251896+00:00
- Reported by: kjkim
- Reported from: user
- Area: agent_rules
- Severity: medium
- Release observed: v1-74c576b27d32
- Status: open

## Summary

wiki upgrade(2026-08-03 20:04, commit c380af2)로 sensitivity_review 결정 권한이 '식별된 사람'에서 'Agent가 inbox-sensitivity/v1 정책·검사 근거에 따라 판단'으로 바뀌었다. inbox-inspection.md는 이 판단 기준을 .circled-wiki/agent-rules/inbox-sensitivity-review.md에서 적용하라고 명시하지만, 해당 파일은 agent-rules/·policies/ 어디에도 존재하지 않는다. 코드(ingest.py)에는 4개 필수 check 키 이름(source_access_scope, personal_context, confidential_business_context, publication_scope)만 상수로 정의되어 있고, 각 check가 무엇을 확인해야 하는지에 대한 실제 정책 서술은 없다.

## Expected result

inbox-inspection.md가 참조하는 inbox-sensitivity-review.md가 존재하고, source_access_scope·personal_context·confidential_business_context·publication_scope 네 항목의 판단 기준과 completed/not_applicable 분기 예시가 문서화되어 있을 것.

## Actual result

find .circled-wiki/agent-rules .circled-wiki/policies -type f 결과에 inbox-sensitivity-review.md가 없음. review-inbox-sensitivity CLI --checks 인자가 요구하는 4개 키 이름은 ingest.py의 SENSITIVITY_REQUIRED_CHECKS 상수로만 확인 가능하고, 각 키의 판단 기준을 설명하는 문서는 어디에도 없음.

## Impact

Agent가 sensitivity_review를 스스로 판단해야 하는 새 모델에서, 판단 기준이 되는 정본 정책 문서가 없어 각 Agent가 4개 check의 의미를 임의로 추정하게 될 위험이 있음. 이는 RB-ROUTE-011/015가 금지하는 '지침 부재·모호성 추정'에 해당할 수 있음.

## Reproduction or context

find .circled-wiki/agent-rules .circled-wiki/policies -type f | sort 실행 → inbox-sensitivity-review.md 없음 확인. grep -rn inbox-sensitivity .circled-wiki/ 결과에도 참조만 있고 실제 파일 없음.

## Cause hypothesis

이번 업그레이드에서 inbox-inspection.md·ingest.py·mcp/server.py는 새 정책 참조명(inbox-sensitivity/v1, inbox-sensitivity-review.md)으로 갱신됐지만, 실제 정책 문서 파일 생성이 배포에서 누락된 것으로 보인다.
